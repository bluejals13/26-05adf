# Compose 핵심 구조

React(Vite) + Spring Boot + MySQL 기반 서비스를 Docker Compose로 통합하고,
Nginx Reverse Proxy·Redis Cache·Prometheus/Grafana 모니터링까지 포함한
실전형 DevOps/SRE 포트폴리오 프로젝트입니다.

## Observability 설계(LGTM)

### 1. Prometheus
```bash
prometheus:
  image: prom/prometheus
```
Spring Metrics 수집
node-exporter 메트릭 수집
cAdvisor 메트릭 수집


### 2. Grafana
```bash
grafana:
  image: grafana/grafana

  ports:
    - "3000:3000"
```
실시간 모니터링 Dashboard
CPU / Memory / JVM / Docker Metrics 시각화


### 3. node-exporter
```bash
node-exporter:
  image: prom/node-exporter
```
수집 메트릭
CPU 사용률
RAM 사용량
Disk I/O
Network 상태


### 4. cAdvisor
```bash
cadvisor:
  image: gcr.io/cadvisor/cadvisor
```
수집 메트릭
Docker Container CPU
Memory
Network
Filesystem 사용량
