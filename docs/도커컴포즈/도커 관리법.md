
## 도커 검증 방법
```bash
# 컨테이너 제거
docker compose down

# 컨테이너 데몬 빌드
docker compose up -d --build

# 컨테이너 제거 //이름 중복 오류 시 사용
docker rm -f <backend>

# 컨테이너 내부 동작 sh cli // -c "curl http://localhost:8080/actuator/health"
docker exec -it <backend> sh

# 컨테이너 톰캣 로그 검색
docker logs backend | grep -i tomcat

# 전체 직전 로그 300
docker logs backend --tail=300


```
