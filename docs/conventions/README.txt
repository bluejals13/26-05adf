# Documentation Conventions

## Purpose

프로젝트 문서 작성 규칙을 정의한다.

---

## Rules

Source of Truth를 먼저 확인한다.

중복 작성을 금지한다.

현재 상태만 Reference에 작성한다.

ADR은 수정하지 않는다.

Roadmap은 문제 중심으로 작성한다.

모든 문서는 Purpose를 가진다.
